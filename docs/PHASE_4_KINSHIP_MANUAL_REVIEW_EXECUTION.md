## 1. 阶段名称

第四阶段 C2：中文亲属称谓人工校对执行记录

## 2. 阶段目标

基于 `docs/PHASE_4_KINSHIP_MANUAL_REVIEW_SAMPLES.md` 中的样本集，用真实家庭数据逐页校对中文亲属称谓展示是否自然、准确、稳妥。

本阶段只做人工校对记录，不新增功能、不修改业务代码、不修改数据库、不新增 migration、不调整 RLS。

## 4. 产品边界

吾家祠堂是：

- 家族关系操作系统
- 私密数字家堂
- 家族记忆资产库

本阶段禁止引入或推动：

- 祭祀化
- 宗教化
- 上香供奉
- 功德
- 法事
- 募捐
- 捐款
- 数字牌位
- 开放社区
- IM
- 支付
- 陌生人社交

## 10. 问题分级

| 等级 | 定义 | 是否阻断 |
| --- | --- | --- |
| P0 | 称谓导致页面白屏、构建失败、核心页面不可用 | 阻断 |
| P1 | 称谓明显错误，影响真实家庭理解或信任 | 阻断进入下一轮扩展 |
| P2 | 称谓可理解但不够自然，需要文案优化 | 不阻断，可排期 |
| P3 | 地域口语差异、复杂亲属链、后续增强项 | 不阻断，暂不做 |

## 11. 通过标准

- 家人档案页称谓显示稳定
- 成员列表页称谓显示稳定
- 三代谱称谓显示稳定
- 2D 图谱标签、筛选、图例显示稳定
- sibling_of 无性别时显示“兄弟姐妹”
- grandparent_of 无性别时显示“祖辈”
- 祖辈视角下孙辈无性别时显示“孙辈”
- 不显示 `KinshipResult.source`
- 不修改关系原值
- 不影响图谱布局、搜索、高亮、筛选、PNG 导出
- 不引入禁止方向

## 13. 下一步建议

完成真实家庭人工校对后，根据问题等级只选择一个方向推进：

1. 如果 P0/P1 大于 0，进入第四阶段 C3：中文称谓 P0/P1 最小修复。
2. 如果 P0/P1 等于 0，仅归档结果，不急于扩展复杂亲属关系。
3. 如果主要是 P2/P3，进入称谓文案优化排期，不立即改动 kinship adapter。
4. 复杂亲属链、地域称谓、父系/母系细分先继续积累样本，不在当前阶段强行实现。
