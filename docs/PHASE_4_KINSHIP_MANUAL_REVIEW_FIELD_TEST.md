## 13. 通过标准

只有同时满足以下条件，才可以进入“称谓校对通过归档”：

- P0 = 0
- P1 = 0
- 家人档案页无明显称谓错误
- 成员列表页无明显称谓错误
- 三代谱无明显称谓错误
- 2D 图谱关系标签、筛选、图例、高亮、导出未被破坏
- 不显示 `KinshipResult.source`
- 不修改关系原值
- 不引入禁止方向

## 14. 下一步判断

根据实测结果选择唯一下一步：

1. 如果 P0/P1 大于 0，进入第四阶段 C5：称谓 P0/P1 最小修复。
2. 如果 P0/P1 等于 0，进入第四阶段 C6：称谓校对通过归档。
3. 如果只存在 P2/P3，进入后续优化排序，不立即扩展复杂亲属关系。
