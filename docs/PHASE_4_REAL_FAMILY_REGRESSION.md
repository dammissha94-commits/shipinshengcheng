# 第四阶段 A：真实家庭数据二轮回归测试

## 1. 阶段名称

第四阶段 A：真实家庭数据二轮回归测试。

## 2. 测试前置条件

- 第三阶段已封板。
- 本地 build 通过。
- Supabase 环境变量正确。
- 真实测试账号可登录。
- 至少存在一个真实 `family_space`。
- 至少存在 5 个 `person_profiles`。
- 至少存在 3 条 `person_relations`。
- 至少存在 1 条 `vote` 类型 `family_meeting`。
- 至少存在 1 条 `family_calendar_event`。
- 至少存在 1 条 `family_story` 或 `family_photo`。

- P2：性能慢、显示不准、局部体验问题。
- P3：文案、样式、低影响问题。
