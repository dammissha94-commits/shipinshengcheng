# 吾家祠堂用户操作手册

这份手册面向参与真实测试的家庭用户。

## 1. 如何注册

1. 打开应用首页。
2. 点击登录入口。
3. 输入邮箱和密码。
4. 如果系统提示需要确认邮箱，请先打开邮箱完成确认，再回到应用登录。

## 2. 如何创建我的家堂

1. 在首页输入你的姓氏。
2. 点击“开始建立我的家堂”。
3. 填写本人姓名和基础信息。
4. 创建成功后，会进入你的数字家堂首页。

## 3. 如何添加家人

1. 进入“ 三代谱 ”页面。
2. 点击要补充的位置，例如父母、配偶、子女。
3. 填写关系、姓名、性别、出生年份。
4. 点击保存。

## 4. 如何查看三代谱

1. 进入数字家堂首页。
2. 点击“三代谱”。
3. 页面会按祖辈、父母、本人 / 配偶 / 兄弟姐妹、子女展示。

## 5. 如何邀请家人认领

1. 先添加需要邀请的家人。
2. 进入“邀请认领”页面。
3. 为对应家人生成邀请链接。
4. 把链接发给家人。

## 6. 家人如何认领

1. 家人打开收到的邀请链接。
2. 登录或注册账号。
3. 确认认领自己的家人档案。
4. 认领成功后，可以补充自己的档案信息。

## 7. 如何补充家人档案

1. 进入“家人成员”。
2. 点击一个家人档案。
3. 有权限时，可以编辑简介、头像链接、生日等信息。
4. 普通成员只能编辑自己的允许字段。

## 8. 如何添加生日提醒

1. 打开自己的家人档案。
2. 找到生日信息。
3. 填写出生月份和出生日期。
4. 保存后，生日提醒会同步到家族日历。

## 9. 如何创建家族故事

1. 进入“家族故事”。
2. 点击新增。
3. 填写标题、年份和故事内容。
4. 保存后，家庭成员可以在列表中查看。

## 10. 如何添加相册记录

1. 进入“家族相册”。
2. 点击新增。
3. 填写相册标题、年份和说明。
4. 当前版本记录相册信息，不做真实图片上传。

## 11. 如何发起家族议事

1. 进入“家族议事”。
2. 有权限的成员可以创建议事。
3. 填写标题、内容和类型。
4. 如果是投票类议事，可以设置选项。

## 12. 如何参与投票

1. 打开一个投票类议事。
2. 查看选项。
3. 选择你的意见并提交。
4. 提交后可以查看投票结果。

## 13. 如何查看家庭节点提醒

1. 进入“家庭节点提醒”。
2. 查看今日、本周、本月和即将到来的提醒。
3. 可以从提醒跳转到家族日历或家人档案。

## 14. 如何生成成果物预览

1. 进入“成果物”页面。
2. 有权限的成员可以生成预览。
3. 当前版本只生成预览记录，不生成真实文件。

## 15. 常见问题

### 登录失败怎么办？

请确认邮箱和密码正确。如果刚注册，请先查看邮箱是否需要确认。

### 为什么我不能添加亲属？

添加亲属需要家堂管理权限。请联系家堂创建者或管理员。

### 为什么我看不到某条内容？

部分内容可能设置为仅创建者或管理员可见。

### 生日只填年份会生成提醒吗？

不会。生日提醒需要填写月份和日期。

### 邀请链接失效怎么办？

请让家堂管理员重新生成邀请链接。
