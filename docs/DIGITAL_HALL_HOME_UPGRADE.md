# 数字化祠堂首页升级

## 结构

```
┌─────────────────────────────────────┐
│ X氏祠堂 Hero                        │
│ 名称 + 成员数 + 已认领/待认领       │
├─────────────────────────────────────┤
│ 家风家训（可编辑）                  │
│ &ldquo;从一段长辈故事中整理家风&rdquo;│
├─────────────────────────────────────┤
│ 4 个核心 CTA                        │
│ 添加亲属 | 家族关系图 | 邀请认领 | 家族动态│
├─────────────────────────────────────┤
│ 待认领亲属（有数据时显示）          │
│ 头像 + 姓名 + 待认领标签            │
├─────────────────────────────────────┤
│ 已故亲人纪念（有数据时显示）        │
│ 头像 + 姓名 + 生卒年 + 生平纪念标签  │
├─────────────────────────────────────┤
│ 常用功能                            │
│ 家人 | 日历 | 故事 | 相册           │
├─────────────────────────────────────┤
│ 双栏：近期节点（左）+ 最近议事（右）│
├─────────────────────────────────────┤
│ 家族记忆（故事卡片）                │
├─────────────────────────────────────┤
│ 底部：完整度 + 故事数 + 家堂设置     │
└─────────────────────────────────────┘
```

## 模块对照

| 需求 | 实现 |
| --- | --- |
| 祠堂名称 | `{surname}氏祠堂` + `displayName` |
| 家族成员数 | profiles.length + claimedCount |
| 家风家训 | 可编辑 textarea，client-state 存储 |
| 家族树入口 | 快捷 CTA → /family/tree/graph |
| 待认领亲属区 | unclaimed.slice(0,4) 网格 |
| 已故亲人纪念区 | deceased.slice(0,4) 网格（living_status='deceased'） |
| 生平记录区 | 通过 /family/members/[id] 详情页查看 |
| 荣耀墙 | 最近故事卡片区 |
| 适老化 | Hero 大字、大按钮 CTA、区块清晰 |
