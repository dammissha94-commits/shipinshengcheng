# 第四阶段：私密家庭 Beta 试用准备

## 1. 版本建议

当前版本建议标记为：

`phase-4-private-family-beta`

该版本适合进入小范围真实家庭试用，不建议直接公开大规模上线。

## 2. 当前结论

| 项目 | 结论 |
| --- | --- |
| 是否可小范围真实家庭试用 | 可以 |
| 是否建议公开上线 | 暂不建议 |
| 是否适合陌生用户开放注册推广 | 暂不建议 |
| 推荐测试范围 | 1 到 3 个真实家庭 |
| 推荐节点规模 | 每个家庭 5 到 20 位家人节点 |
| 是否需要继续观察隐私风险 | 需要 |

## 3. 已具备条件

- 核心闭环已经具备：登录、建堂、添加亲属、家族树、邀请认领、人生记忆、家堂档案。
- 第四阶段已完成多轮文档归档与自动检测。
- `npx tsc --noEmit` 最近通过。
- `npm run lint` 最近通过。
- `npm run build` 最近通过。
- `.env.example` 不含真实密钥。
- `.env.local` 未被 git 跟踪。
- `relationship-ts` 只通过 kinship adapter 使用。
- 当前未发现支付、IM、开放社区、祭祀化业务入口。

## 4. Beta 使用边界

Beta 期间建议：

- 只邀请真实熟人家庭。
- 不做公开宣传。
- 不开放陌生人社区。
- 不上传高度敏感照片。
- 不录入身份证、手机号、详细住址等高敏感信息。
- 不将邀请码公开发布到群外或社交平台。
- 每轮测试后整理 P0/P1/P2/P3 问题。

## 6. Beta 前必须知晓的限制

| 限制 | 影响 | 建议 |
| --- | --- | --- |
| 中文称谓真实家庭人工校对未完全填写 | 个别称谓可能不够自然 | 继续按 C4 表格填写 |
| 相册 Storage bucket 当前存在 public 读策略 | 如果照片 URL 泄露，可能被非成员访问 | Beta 先避免敏感照片，正式上线前改为私有 bucket 或签名 URL |
| visibility 中存在“公开可见”文案 | 用户可能误解为互联网公开 | 后续建议改为更清晰文案，如“家堂内公开” |
| 当前 git 工作区存在大量未提交改动 | 不利于版本回滚 | Beta 前建议整理提交 |
| 未完成生产环境 RLS 实库审计 | 本地 migration 不等于线上状态 | 正式上线前必须查线上 policy |
